# 🏙️ CITY LIFE – עיר בלי גבולות
### High-Quality 3D Open-World Life Simulation Game

> שילוב מנצח של עולם פתוח בסגנון GTA, סימולטור חיים וסימולטור נהיגה תלת־ממדי מתקדם – ישירות בדפדפן!

---

## 🎮 תיאור המשחק (Game Overview)

**CITY LIFE – עיר בלי גבולות** הוא משחק עולם פתוח תלת־ממדי מלא ואינטראקטיבי שנבנה באמצעות **Three.js**, **React** ו-**TypeScript**.

השחקן מתחיל בדירה צנועה בשכונת החוף הדרומית עם רכב בסיסי ו-$5,000 בכיס. מטרת המשחק היא להתקדם בעולם הפשע והעסקים החוקיים, לרכוש רכבי על, לקנות פנטהאוזים ווילות פאר, לפתוח עסקים מניבים, לבצע חוזים ומשימות, ולהפוך לשליט הבלתי מעורער של המטרופולין.

---

## ✨ תכונות עיקריות (Key Features)

### 1. עיר ענקית ומפורטת (The Open-World City)
* **מרכז העיר (Downtown Skyscrapers):** גורדי שחקים ענקיים עם חלונות מוארים בלילה, מנחת מסוקים (Helipad), אנטנות עם אורות אזהרה מהבהבים, פלאזות ומשרדי תאגידים.
* **שכונת יוקרה (Sunset Hills):** וילת פאר מודרנית עם בריכת שחייה מוארת, מיטות שיזוף, מרפסות זכוכית ומוסך פרטי ל-5 רכבים.
* **שכונת מגורים (Residential Suburbs):** בניין הדירה ההתחלתית של השחקן, בתים פרטיים ורחובות פרבריים.
* **חוף ים וטיילת (South Beach & Marina):** חוף חול מוזהב, דקלי קוקוס, מזח עץ הנמתח אל תוך האוקיינוס ויאכטת פאר עוגנת.
* **שדה תעופה בינלאומי (International Airport):** מסלול המראה ארוך (09L) עם סימוני מסלול, תאורת מסלול ירוקה/לבנה, מגדל פיקוח והאנגר עם מטוס מנהלים פרטי שניתן להמריא איתו!
* **כבישים מהירים וגשרים:** רשת כבישים מרובת נתיבים, גשר עילי תלוי (Overpass Bridge), רמזורים עובדים (אדום/צהוב/ירוק) ותאורת רחוב לילית.
* **תנועה חיה (AI Traffic & Pedestrians):** מכוניות אזרחיות הנוסעות בכבישים ועוצרות כדי לא להתנגש, והולכי רגל המטיילים על המדרכות.

---

### 2. רכבים וסימולציית נהיגה (Vehicles & Realistic Driving)
* **רכבים זמינים:**
  1. **CityRunner Compact** (רכב ההתחלה של השחקן - חסכוני וזריז).
  2. **Venom V8 Muscle** (מכונית שרירים אמריקאית עוצמתית עם צליל מנוע עמוק).
  3. **Starlight Prestige** (סדאן מנהלים יוקרתית עם נוחות נסיעה מרבית).
  4. **Titan 4x4 Offroader** (רכב שטח מוגבה לכל תנאי דרך).
  5. **Apex GT Hypercar** (מכונית-על סופר מהירה עם כנף אחורית אווירודינמית).
  6. **SkyLiner Private Jet** (מטוס מנהלים בשדה התעופה המאפשר טיסה מעל העיר!).
* **מכניקת נהיגה:**
  - האצה מדורגת, בלימה והילוך אחורי (Reverse).
  - בלם יד (Handbrake / Space) המאפשר סחיפות ודריפטים בליווי חריקת צמיגים ועשן.
  - בוסט ניטרו (Nitro / Shift) עם להבות כחולות מהאגזוז ואפקט מתיחת מצלמה (FOV Punch).
  - פנסי חזית (Headlights) המאירים קדימה אל תוך הלילה באור זרקור אמיתי, ואורות בלימה אחוריים הזוהרים בעת בלימה.
  - צופר (Horn / H key) פעיל.

---

### 3. מוסך שיפורים והתאמה אישית (Neon Auto Works Garage)
כניסה למוסך השיפורים ברחבי העיר מאפשרת:
* צביעת הרכב במגוון צבעים יוקרתיים (Ultra Blue, Crimson Fury, Cyber Green, Sunset Gold, Matte Black ועוד).
* הוספת תאורת ניאון תחתונה (Underglow Neon) בצבעי טורקיז, ורוד לוהט, ירוק רעיל וסגול עמוק.
* שדרוגי מנוע (ECU Stage 1, Stage 2, Stage 3) המעלים מהירות מרבית ותאוצה.

---

### 4. נדל"ן, פנטהאוזים וחללים פנימיים (Real Estate & Interiors)
השחקן יכול להיכנס לתוך נכסים:
* **דירת סטודיו ראשונית:** חדר מעוצב עם ספה יוקרתית, טלוויזיית 4K, מטבחון, מרפסת הפונה לקו הרקיע של העיר ומיטה נוחה. **בלחיצה על E ליד המיטה ניתן ללכת לישון ולקדם את הזמן לבוקר (08:00)!**
* **פנטהאוז מרינה ביי (Marina Bay Penthouse):** קומה עליונה עם רצפת שיש לבנה, בר משקאות יוקרתי, שנדליר וקירות זכוכית המשקיפים לאוקיינוס.
* **וילת סנסט הילס (Sunset Hills Villa):** אחוזת ענק עם בריכה ומרפסת שמש.

---

### 5. כלכלה, עסקים ומשימות (Economy, Businesses & Missions)
* **יתרת פתיחה:** $5,000.
* **עסקים מניבים הכנסה פסיבית:**
  - **QuickBite Cafe & Bistro** ($25,000 - מייצר $220 לדקה).
  - **Neon Custom Tuning Garage** ($85,000 - מייצר $750 לדקה).
  - **Apex Motors Showroom** ($260,000 - מייצר $2,600 לדקה).
  - **Skyline Ultra Nightclub** ($650,000 - מייצר $7,200 לדקה).
  - צבירת רווחים אוטומטית שניתן למשוך בכל רגע באפליקציית הבנק!
* **משימות ואתגרים (Contracts):**
  - **High-Speed Express Courier:** משלוח מסמכים דחוף נגד השעון ($3,500).
  - **Downtown Midnight Sprint:** מרוץ רחוב לילי בין נקודות ביקורת ($6,000).
  - **VIP Celebrity Chauffeur:** הסעת כוכב בינלאומי משדה התעופה לוילה ($9,500).
  - **Highway Speed Record Challenge:** שבירת מהירות של מעל 160 קמ"ש בגשר המהיר ($12,000).
  - **Exotic Supercar Delivery:** הובלת רכב-על מהנמל לסוכנות ($22,000).

---

### 6. מחזור יום ולילה ומזג אוויר דינמי (Day/Night & Weather)
* מסלול שמש וירח ריאליסטי המשנה את צבעי השמיים, הצללים והערפל:
  - **בוקר זוהר (Sunrise):** שעות זהב חמימות.
  - **צהריים (Midday):** שמש בהירה ושמיים כחולים.
  - **שקיעה דרמטית (Sunset):** גווני ארגמן וכתום.
  - **לילה (Night):** שמי כוכבים, פנסי רחוב מוארים וגורדי שחקים זוהרים באורות ניאון.
* מזג אוויר משתנה: שמיים בהירים או סופת גשם (Rainstorm) עם חלקיקי גשם והשתקפויות על הכביש הרטוב.

---

### 7. מערכת סאונד מובנית (100% Procedural Web Audio API)
* **אפס תקלות טעינה / CORS:** כל הסאונד מיוצר מתמטית בזמן אמת!
* מנוע סינתסייזר המשנה גובה צליל (Pitch) לפי סל"ד (RPM) ומהירות.
* חריקת צמיגים ריאליסטית בסחיפות.
* רעש שאיבת ניטרו ופיצוצי אגזוז.
* צלילי צעדים על אספלט ומדרכות.
* צליל קופה רושמת ("צ'ה-צ'ינג") בקבלת והוצאת כספים.
* **רדיו מובנה ברכב (R key):** 3 תחנות רדיו עם ביטים ממוחשבים (CityWave 80s Synthwave, Cyber Beats FM, Sunset Chillhop).

---

### 8. ממשק משתמש פרימיום (Modern HUD & Smartphone)
* **רדאר / מיני-מפה (GTA Style Mini-Map):** מפה מעגלית המסתובבת עם השחקן, מציגה כיוון צפון, מיקום רכבים, נקודות עניין, סוכנויות ומטרת משימה.
* **ספידומטר דיגיטלי:** מציג מהירות קמ"ש בזמן אמת, הילוך נוכחי (1-6 / R) ומד ניטרו.
* **סמארטפון אינטראקטיבי (Tab / Phone Icon):**
  - אפליקציית **LifeBank** (יתרה, פירוט עסקאות, משיכת רווחי עסקים).
  - אפליקציית **Motors Dealership** (קניית רכבים).
  - אפליקציית **Dynasty 8 Real Estate** (קניית דירות ווילות).
  - אפליקציית **Contracts** (בחירת משימות).
  - אפליקציית **Valet** (הזמנת הרכב שלך ישירות לידך בלחיצה אחת!).
  - אפליקציית **Settings** (שינוי שעת יום/לילה, מזג אוויר וכפתור מענק מפתחים לבדיקות).
* **מפת עיר מלאה (M key):** מפת לווין עם שמות האזורים ונקודות עניין.
* **תמיכה במסכי מגע (Mobile / Tablet Touch Controls):** ג'ויסטיק ודוושות על המסך.

## ⌨️ מקשי שליטה (Controls Guide)

| פעולה | מקש במקלדת |
| :--- | :--- |
| **תנועה / נהיגה** | `W`, `A`, `S`, `D` או מקשי החצים |
| **ריצה / ניטרו** | `Shift` |
| **קפיצה ברגל / בלם יד ברכב** | `Space` |
| **כניסה / יציאה מרכב** | `F` |
| **אינטראקציה (דלתות, שינה, חנויות)** | `E` |
| **סמארטפון** | `Tab` |
| **מפת עיר מלאה** | `M` |
| **צופר רכב** | `H` |
| **החלפת תחנת רדיו** | `R` |
| **החלפת מצב מצלמה (מכסה מנוע / מרדף)** | `C` |
| **מבט מצלמה** | תזוזת עכבר (Mouse Orbit) |

## 🚀 הרצה מקומית (How to Run)

הפרויקט מוכן לחלוטין. להרצה מקומית בסביבת פיתוח:

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח
npm run dev
```

לביצוע Build לייצור:
```bash
npm run build
```
